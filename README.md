## Overview
This project is an Excel-based application built using VBA that analyzes student grades and automatically generates a formatted Word report.

It allows users to process grade data, compute key statistics, and export results into a professional report with tables and visualizations.

---

## Features
- Analyze student grades (max, min, average, standard deviation)
- Identify highest and lowest performing students
- Generate frequency distribution table
- Create histogram chart of grade distribution
- Export a formatted report to Microsoft Word
- Simple ribbon-based interface (Analyze, Export, Clear)
